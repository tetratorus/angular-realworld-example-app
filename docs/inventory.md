## Cross-cutting behaviour

- **Auth state** (`UserService`): `loading` → `authenticated` / `unauthenticated` / `unavailable` (5xx on `GET /user`, keeps token, retries 2s, 4s, 8s, 16s…). App initializer blocks first render until `GET /user` resolves.
- **Token**: `localStorage.jwtToken`, sent as `Authorization: Token <jwt>`.
- **Errors**: normalised to `{ errors: {field: [msg]}, status }`; network failure → `network Unable to connect…`. 401 on any endpoint except `/user` logs out.
- **Header**: 4 variants (signed out / signed in / unavailable / loading). Footer shows current year.
- **Debug hook**: `window.__conduit_debug__ = { getToken, getAuthState, getCurrentUser }` used by the official e2e suite.
- **Pipes**: `defaultImage` (null → `/assets/default-avatar.svg`), `markdown` (marked + sanitise), Angular `date:'longDate'`.
